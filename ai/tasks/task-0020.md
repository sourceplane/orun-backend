- catalog queue, default `orun-catalog-ingest`
- catalog DLQ, default `orun-catalog-ingest-dlq`
- Worker script with DO/D1/R2/queue producer bindings
- Worker queue consumer attached to the catalog queue
- cron schedule `*/15 * * * *`
- Worker vars and secrets

- `--catalog-queue` default `orun-catalog-ingest`
- `--catalog-dlq` default `orun-catalog-ingest-dlq`

count. It must not print secrets.

Non-dry-run must be idempotent. Running init twice should reuse resources,
reapply only missing migrations, leave secrets secret, and report ready state.

Store non-secret queue/DLQ/cron metadata in the bootstrap config so status and
destroy can operate on the exact managed resources.
