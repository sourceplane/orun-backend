Cloudflare deployment, then prove catalog sync can enqueue an R2-reference
message and have the Worker queue consumer normalize it end to end.

Keep this task focused on queue activation and production-readiness hardening.
Do not activate catalog D1 shards yet.

   - Drop and ack messages where `namespaceId !== repoId`.
   - Drop and ack envelopes where `envelope.uploadId !== message.uploadId`.
   - Prefer safe opaque drop reasons. Do not log component paths, raw envelope
     bodies, JWTs, tokens, secrets, or arbitrary user payloads.
   - Add regression tests for both new drop cases.

   - Add a producer binding named `CATALOG_INGEST_QUEUE`.
   - Add a consumer entry for the same queue.
   - Use a stable production queue name such as `orun-catalog-ingest`.
   - Choose conservative queue settings suitable for catalog normalization
     (`max_batch_size`, `max_batch_timeout`, `max_retries`, and either a DLQ or
