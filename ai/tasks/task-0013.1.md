# Objective

Fix catalog sync validation so malformed catalog envelopes fail synchronously with typed JSON errors before the Worker returns `202`.

# Required Outcomes

1. `POST /v1/catalog/sync` rejects missing `component.path`.
2. `POST /v1/catalog/sync` rejects non-string `component.path`.
3. Add regression tests for omitted and non-string paths.
4. Tighten `components` validation so `envelope.components` must be an array. Empty arrays may remain valid if intentional.
5. Add or update tests proving no R2 write or `ctx.waitUntil` normalization is scheduled for those invalid envelopes.
6. Optional but recommended: reserve or record `uploadId` synchronously before scheduling async normalization, or document why duplicate upload races remain deferred.
